#REQUERIMIENTOS

I. REQUERIMIENTOS FUNCIONALES //¿que hace el sistema?

1. RF-CLI-01| El cliente podrá registrarse en la plataforma web.
2. RF-CLI-02| El cliente podrá iniciar sesiòn.
3. RF-CLI-03| El cliente podrá cerrar sesiòn.
4. RF-CLI-04| El cliente podrá recuperar contraseña.
5. RF-CLI-05| El cliente podra editar sus datos personales.
6. RF-CLI-06| El cliente podrá visualizar sus datos personales.
7. RF-CLI-07| El cliente podrá visualizar los productos en exisitencia,.
8. RF-CLI-08| El cliente podrá visualizar tips de crochet.
9. RF-CLI-09| El cliente podrá visualizar resultados de otras crocheteras.
10. RF-CLI-10| El cliente podrá comprar patrones digitales mediante la plataforma. 
11. RF-CLI-11| El cliente podrá publicar fotografìas de sus proyectos elaborados con los patrones adquiridos. 
12. RF-CLI-12| El cliente podrá comentar la publicaciones de otros usuarios. 
13. RF-CLI-13| El cliente podrá recuperar contraseña.
14. RF-CLI-14| El cliente podrá consultar historial de comprar.
15. RF-CLI-15| El cliente podrá descargar patrones comprados.
16. RF-CLI-16| El cliente podrá buscar patrones.
17. RF-CLI-17| El cliente podrá filtrar patrones por categoría. 
18. RF-CLI-18| El cliente podrá consultar el detalle de un patrón. 
19. RF-ADM-01| El administrador podrá acceder a la plataforma a traves de su registro.
20. RF-ADM-02| El administrador podrá consultar los usuarios regristrados en la plataforma.
21. RF-ADM-03| El administrador podrá registrar nuevos patrones digitales. 
22. RF-ADM-04| El administrador podrá publicar tips de crochet
23. RF-ADM-05| El administrador podrá publicar trabajos destacados de clientes. 
24. RF-ADM-06| El administrador podrá editar archivos de los patrones digitales, e información de tips y resultados.
25. RF-ADM-07| El administrador podrá eliminar archivos de los patrones digitales, e información de tips y resultados.
26. RF-ADM-08| El administrados podrá consultar el historial de compras y validar los pagos realizados mediante transferencia o deposito.  
27. RF-ADM-09| El administrador podrá habilitar el acceso a los patrones una vez confirmado el pago. 
28. RF-ADM-10| El administrador podrá gestionar las categorías.
29. RF-ADM-11| El administrador podrá gestiorar comentarios. 
30. RF-ADM-12| El administrador podrá bloquear usuarios.
31. RF-ADM-13| El administrador podrá cambiar precios de patrones. 
32. RF-ADM-14| El administrador podrá consultar reportes de ventas. 

II. REQUERIMIENTOS NO FUNCIONALES //Calidad del sistema o sus procesos

1. RNF-01-SEGURIDAD | Las contraseñas deberán almacenarser de forma cifrada. 
2. RNF-02-RENDIMIENTO | Las páginas deberán cargar en menos de 3 segundos con una conexion estable.
3. RNF-03-COMPATIBILIDAD | El sistema deberán ser compatible con Google Chrome, Microsoft Edge, Mozilla Firefox.
4. RNF-04-RESPONSIVE | La interfaz deberá adaptarse correctamente a dispositivos móviles, tabletas y computadoras.
5. RNF-05-DISPONIBILIDAD | El sistema deberá estar disponible las 24 horas.
6. RNF-06-BASE DE DATOS | La información sera almacenada en SQL Server.
7. RNF-07-TECNOLOGÍA | El sistema será desarrollado utilizando ASP.NET Core MVC y Entity Framework Core.
